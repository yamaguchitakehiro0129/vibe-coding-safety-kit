# 03. 法規制

知らなかった、は通用しない。

---

## まず、考え方から

法律の前では、悪意の有無は問われない。
意図せず違反しても、責任は発生する。

「個人だから大丈夫」「小さいから見逃される」も、通じない。
損害賠償で済む話と、刑事罰になる話があり、どちらに転ぶかは事前にはわからない。

リリース前に5分、考える。
それだけで、未来の数百万円と、信頼を守れる。

---

## チェックリスト

### A. 個人情報

- [ ] 個人情報を扱うかを、明確に把握している
- [ ] プライバシーポリシーを公開している
- [ ] 取得・保管・削除の方針を、文章で説明できる
- [ ] EUのユーザーが触る可能性がある場合、GDPRを確認した
- [ ] 取得時に、利用目的を明示している

「氏名」「メール」「住所」「電話番号」だけが個人情報ではない。
IPアドレス、Cookie ID、位置情報、購買履歴の組み合わせも、個人を特定しうる情報になる。

### B. 業法規制

- [ ] そのサービスが、特定の業法の対象でないかを確認した
- [ ] 医療、金融、法律、教育、不動産、運送、酒類、たばこ、賭博、性風俗、職業紹介など、業法のある領域に踏み込んでいない
- [ ] 該当する場合、必要な許認可を取得している

「相談に乗るアプリ」は、相手によっては医療相談になる。
「お金の使い方をアドバイスするAI」は、金融商品取引法に触れる可能性がある。
「マッチングアプリ」は、出会い系サイト規制法の対象になる。

軽い気持ちで作ったアプリが、業法の網にかかっていることは珍しくない。

### C. データの取得元

- [ ] 他社サイトをスクレイピングしていない、または利用規約で許可されている
- [ ] APIを利用する場合、利用規約に違反する使い方をしていない
- [ ] データセットを使う場合、ライセンスを確認した
- [ ] 著作物（画像・文章・音楽）を、許可なく学習・配信に使っていない

「公開されている」と「使っていい」は、別である。
ウェブに公開されているデータでも、利用規約や著作権の制約は残っている。

### D. ライセンス（依存ソフトウェア）

- [ ] 使っているライブラリのライセンスを、すべて把握している
- [ ] GPL系ライブラリを、商用クローズドソースに組み込んでいない
- [ ] AGPLライブラリを、SaaSとして提供していない
- [ ] 表示が必要なライセンス（MIT, Apache 2.0等）の表示を、忘れていない

ライセンスの違反は、ある日突然、削除要求や訴訟として降ってくる。

### E. AI生成物

- [ ] AIで生成した画像・文章・音声・コードの著作権リスクを把握している
- [ ] 商用利用が許可されているサービス・モデルを使っている
- [ ] 既存作品に酷似した出力を、そのまま公開していない
- [ ] 生成物に対する自社の権利範囲を、利用規約で確認した

AI生成物の権利関係は、各国で議論が続いている。
今、合法に見える使い方も、将来覆る可能性がある。

### F. 特定商取引法（日本国内向け）

- [ ] 商品・サービスを販売する場合、特定商取引法に基づく表記をサイトに掲載している
- [ ] サブスクリプションの解約導線を、わかりやすく設計している
- [ ] ダークパターン（解約を妨げる設計）を使っていない

2022年以降、ダークパターンへの規制は急速に厳しくなっている。

### G. 利用規約と免責

- [ ] 利用規約を作成・公開している
- [ ] 免責事項を、現実的な範囲で記載している
- [ ] 紛争解決の管轄裁判所を明記している
- [ ] 規約の変更手続きを、明記している

無料サービスでも、利用規約は要る。
「無料だから免責される」という考えは、法律的には危うい。

---

## ありがちな事故パターン

* スクレイピングしたデータを使ったサービスを公開し、運営元から差し止め請求を受ける
* AI生成した画像が既存キャラクターに酷似しており、SNSで炎上後に法的措置を受ける
* 個人情報の取得時に同意を取らず、後から削除要求が来てデータベース改修に追われる
* GPL系ライブラリを組み込んだまま商用展開し、ソースコード公開を要求される
* 解約しづらい設計が問題視され、消費者庁から行政指導を受ける

## AIに聞くときの観点

* 「このサービスは、日本のどの業法の対象になりうるか」
* 「このライブラリのライセンスを、商用SaaSで使う場合の制約は何か」
* 「個人情報を扱うサービスで、最低限用意すべき法的書類は何か」

## より深く学ぶための原典

* **個人情報保護委員会(PPC)** — 個人情報保護法の所管官庁。ガイドライン・Q&A・漏えい等報告の手順が公開されている
* **総務省・経済産業省「AI事業者ガイドライン(第1.1版)」** — AIを業務で使う側、提供する側の統一指針。バイブコーディングを業務として行う場合、利用者としての責務を確認しておく
* **AI セーフティ・インスティテュート(AISI)「AI セーフティに関する評価観点ガイド」** — AIの安全性評価の観点が体系化されている
