## 確認したこと

### 動作確認

- [ ] ローカルで動作確認した
- [ ] ステージング環境で動作確認した
- [ ] 影響範囲のテストが通っている

### AI生成コードのレビュー

このPRに含まれるAI生成コードについて、以下を確認した。

- [ ] AIが提案したライブラリが、実在する
- [ ] AIが提案したライブラリが、メンテナンスされている
- [ ] AIが書いた認可チェックを、自分で読んで理解した
- [ ] AIが書いた入力検証を、自分で読んで理解した
- [ ] AIが書いたテストの中身を、自分で読んで理解した
- [ ] AIが追加した依存関係を、`package-lock.json` 等で固定した

### セキュリティ

- [ ] 新しく追加したシークレットが、コードに直書きされていない
- [ ] エラーメッセージで、内部情報が漏れていない
- [ ] ユーザー入力が、サーバー側で検証されている
- [ ] 認可チェックが、データを返す前に実行されている

### データ

- [ ] スキーマ変更がある場合、ステージングで試した
- [ ] スキーマ変更がある場合、ロールバック手順を確認した

### 性能

- [ ] N+1問題が発生していない
- [ ] 大量データで遅くなる箇所がない
- [ ] 外部API呼び出しに、タイムアウトが設定されている

### 法的・コスト

- [ ] 個人情報の扱いに変更がある場合、プライバシーポリシーとの整合を確認した
- [ ] 新規API呼び出しの増加が、月額コストに与える影響を試算した
